# v1.0 Public Artifact

This directory records the first public-release target for *Mechanistic Localization Is Distribution-Relative*.

The release is intended to freeze four linked artifacts from one scientific source:

- the identified manuscript PDF at repository root;
- the standalone identified arXiv source package and ZIP;
- the standalone anonymous ICLR 2027 source package and ZIP;
- the finite regression and validation records used to audit the release.

The public-release gate requires `make all` to pass from a clean checkout. Source hashes for the frozen release are generated after the initial population PR is merged and the build workflow has produced the final packages.
