# v1.0 Public Artifact

This directory records the first public-release target for *Mechanistic Localization Is Distribution-Relative*.

The release freezes four linked surfaces from one scientific source:

- the identified manuscript PDF at repository root;
- the standalone identified arXiv source package and ZIP;
- the standalone anonymous ICLR 2027 source package and ZIP;
- the finite regression, claim, and validation records used to audit the release.

The public-release gate is `make all` from a clean checkout. That command runs the finite regressions, constructs both standalone submission directories and ZIPs, compiles both manuscript variants, verifies the ZIP manifests and identity/anonymity invariants, recompiles the extracted ZIPs, builds the stable identified PDF, and writes `SHA256SUMS.txt`.

`SHA256SUMS.txt` records the generated PDF and ZIP hashes together with the canonical scientific source files used for this release. It is regenerated by the build rather than maintained by hand.

Scientific changes after v1.0 should create a new release record rather than silently changing the meaning of this frozen release.
